# 语义空间连接与大喊：真实 Console 进程验收

2026-11-01。独立验收代理操作实际 Human Console 入口，验证[空间连接与大喊](../design/spatial-relations-and-shout.md)的召集闭环。这不是用户本人试玩，本记录没有真实 LLM 调用。全部场景由普通游戏命令创建，不编辑存档，不关闭需求或天气。

## 运行与证据

使用主线程构建的 Release DLL，验收代理未运行 build、test 或 `dotnet run`。启动形式为：

```powershell
dotnet src/ResourceCycle.Cli/bin/Release/net10.0/DramaBoard.ResourceCycle.Cli.dll `
  --survival --characters 3 --store artifacts/shout-playtest-20261101/three-person
```

创建后省略人数，退出真实进程再冷开同一存档。`artifacts/shout-playtest-20261101/` 保存 `run-stage.ps1`、15 阶段的原始 stdin/stdout/stderr、新增操作配对、完整存档、二进制哈希、`verify.py` 和 `acceptance.json`；大文件和存档不提交。`verify.py` 的 13 组断言通过。所有进程正常退出，未进行超时终止。

| --- | --- |

| 02，16:00 | a 确认食物警告后继续等待；b 抵达溪流湾并 `gather water 1`，原定 16:15 完成；c 一次 `shout ColdWind Terminal 收好水后回营地跟随我；"集合" **原文**`。a 同地、b 邻地均收到署名原文。 |
| 03 | 冷开后 a 仍等到 17:00，b 仍采集至 16:15；两人分别 `continue` 确认通信，c 再等一小时。b 在原到期时刻取得 1 份水，没有重启或取消采集。 |
| 04 | b 尝试远程 `follow c` 被持久拒绝；随后普通 `go trail-1` 回营，预计 17:15 抵达。声音没有授予远程交互权限。 |

| 06 | 17:30 饮水警告使三人各自补给并确认；18:00 只有领队 c 输入 `go trail-1`，19:00 三人一起抵达溪流湾，a/b 仍跟随 c。 |
| 10，复验构建 | 冷开阶段 06 的存档；`:mode full`、两种 `:layout ... once`、`:look`、`:exit` 后，除宿主 `operations.jsonl` 外所有游戏文件哈希不变，仍为 19:00、溪流湾、c 领队及两名队员。 |

活动期限、成果、操作角色以每阶段新增配对收据和当前个人材料交叉验证；不把冷开重绘的历史文字当作新事件。三人同场景先后操作也没有产生伪造的接收者 `shout` 或随行者 `go` 调用。

## 边界对照与信息保护

- **途中排除与空听众**：独立三人局让 a/b 先出发，c 留营地喊出唯一标记，再等待。a/b 到达后都没有该标记，也没有待响应通信。阶段 07–08 初验，阶段 12 在复验构建完整重做。另用单人局验证无人听众仍成功；冷开后再次发声额度从 3 降到 2，没有重置。
- **声音双向关系**：阶段 14 在复验构建中由溪流湾的 b 大喊，同地 a 和营地 c 均收到新原文，补充首批 camp→stream 方向。
- **回执不泄露听众**：复验构建中，c 向两个跟随者喊话的回执与两个同伴均在途中时的零听众回执完全一致，都是“已大喊”及自己额度从 4 到 3。
- **活动与提醒独立**：首批 c 喊话没有确认其食物警告，后续 `wait 1` 才明确确认；a/b 接收后确认通信只改变待响应标记，活动按原期限完成。复验构建的跟随者接收也没有脱队。
- **全文、安全与知识边界**：`ColdWind`、`Terminal`、引号和 Markdown 原文保留为角色话语，注明未经世界证实；引号安全转义，没有作为天气或终局标签解释。营地接收者材料没有出现未知的“溪流湾”，也没有远处听众名单。两种布局、full/delta 及冷开都读取个人冻结材料。
- **操作证据**：合计 38 条新游戏操作，37 成功、1 条有意的远程跟随拒绝；每条都有且只有一个结果，ToolCallId 配对一致，游戏结果含 WorldVersion 和 DomainEvent。查看/布局/退出元命令另存，不混入游戏操作数量。

## 发现与限制

首批成功大喊回执显示“本时刻剩余交流次数：-1 次”，实际是额度差量，却用了剩余值标签。报告给主线程后，复验构建改为明确的 `4 次 → 3 次`；阶段 11–14 已在真实入口复验，历史已保存回执仍保留原文字。

本记录未验证真实 LLM 自主理解与协作、E-only 中断、畸形事实拒绝、二跳边界、完整获救或真人体验；这些不能由上述脚本轨迹推导。空间二跳、领域事实校验与磁盘恢复由本次相应自动测试分别覆盖，不能将代理操作 Human Console 称为用户验收。
