# Goal 启动文本

供用户在 DramaBoard 仓库启动持续工作时使用。这里只提供项目任务文本，不规定 `/goal` 的产品语法或预算参数；编辑文档不启动 Goal。实际执行遵守当前用户指令、平台约束及仓库协作规则。

```text
请在 E:/repos/Atelia-org/drama-board 持续推进“小镇与山野：可持续模拟的小世界”，直到 docs/codex-goals/living-world/README.md 的 C1–C8 完成条件全部满足。

先读 AGENTS.md、PROJECT-STATE.md，以及 docs/codex-goals/living-world/ 下的 README.md、approach.md、execution.md、work-plan.md。核对实际源码、工作树和已有证据，接续未完成的工作；不要每轮从头设计，也不要覆盖用户或其他会话的改动。

融合 Microtown 和 ResourceCycle，形成一个连续世界：角色在镇内生活、生产、交换，也能到附近山里采集、探索与求生，再返回继续生活。没有强制主线或固定天数的世界终局。Human Console 同时服务真人与通过终端游玩的 Coding Agent；若干其他角色由真实 LLM 驱动。

每轮自主选择最有价值、可验收的下一目标，完成必要调查、设计、实现、验证和交接，然后继续尚未满足的条件。具体名称、内容、数值、API、重构路径与常规可逆决策自行裁定；没有旧开发存档兼容包袱，按需 Git 提交。优先完成连续生活循环，不先建立万能平台。

采用 $bounded-delegation 按需组织有界工作包与独立复核，主线程负责契约、集成和证据验收；重大争议或复杂性膨胀时按需使用 $dialectical-simplification。遇到设计问题，可以查证成熟游戏的相似设计，提取体验作用，实施适合本项目的简单机制，记录来源与取舍。不要把调研变成开工前置工程。

必须实际运行与游玩。工程验收、离线 fixture、真实模型和自由游玩分别留证据。允许 Coding Agent 不带测试清单进入 Human Console 自由行动，结束后再以开发者视角反思；不借隐藏状态、代操作或修改存档制造成功，不把 Agent 体验说成真人验收。真实调用使用已有授权与可用凭据，每次预先声明有限预算和停止条件，秘密不落盘到文档或日志。

维护 work-plan.md 作为唯一专题施工状态：当前缺口、下一步、证据和少量待决项；设计结论写回相关文档，根 PROJECT-STATE 只保留摘要导航。遇到难以决定的问题，先完成不受影响的部分；真正需要用户价值判断的事项给出具体选项、推荐和代价，不因常规细节反复停工。

完成以 README 的 C1–C8 为准，不能以代码存在、构建通过、预算耗尽或子代理报告冒充完成，也不要无限加入新功能。达到条件后交付启动/续局说明、工程与实际运行证据、剩余限制和少量可选决策。平台停止或外部阻碍导致未完成时如实保留状态，不降低条件。
```
