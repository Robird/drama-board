# 研究设计：因果边界、规则与提前推理

状态、完成条件与后续 Goal 入口见 [README](README.md)，具体对照和计量见[实验协议](experiment-protocol.md)。本文中的概念不是已经存在的公共 API，也不要求各自成为类型。

## 五个研究问题

| 问题 | 可证伪的研究假设 | 必须回答的边界 |
| --- | --- | --- |
| RQ1 规则约束 | 有限作用域、跨域最短延迟和明确共享资源，可以增加可利用的推理并行度。 | 哪些约束有效？零延迟连锁、远程操作、共享市场怎样破坏隔离？表达与交互代价是什么？ |
| RQ2 向外影响 | 有限时域内，能够以较低成本估计小于整个世界的保守影响包络。 | 未知行动的并集、已知行动及实际影响如何区分？哪些动态变化需要重算？ |
| RQ3 向内失效 | 反向依赖和最早到达边界，可以识别预计输入仍然成立的窗口。 | 外部影响改变信息或唤醒的路径是否完整？可预测的内部演化如何进入预计输入？ |
| RQ4 调度策略 | 串行确认下，有界提前推理在低耦合场景有收益，混合安全策略能控制废弃成本。 | 何时值得投机、投机多少？服务拥塞、角色公平与预算会不会抵消收益？ |
| RQ5 工程价值 | 原型能接入当前实际角色材料和提交机制，而不引入完整世界回滚或第二个持久化权威。 | 最小接缝、日志归属、反馈副作用、暂停/恢复、代码维护成本是什么？ |

假设不成立时留下适用范围和反例。不得以模型自己声称“参考了哪些信息”作为依赖证明。

## 最小因果模型

### 两种时间、两个边界

- **模型时间（ModelTime，也称模拟时间）**描述世界何时发生变化。同一模拟时刻仍有逻辑次序与事件种类优先级，不能把相同 tick 当作可交换。
- **墙钟时间（WallClockTime）**描述请求、计算、排队与等待，用单调计时测量。模型晚返回不会自动消耗模拟时间。
- **来源边界**是预测依据的真实已提交 S；**采用边界**是实际轮到该角色且通过验证的位置。预测目标时间/唤醒代次/预计 Context 是假设，不能伪造为已提交边界。
- 模型输入是实际送入 Completion 的完整有效请求，包含 Shared、Tail、工具合同、模型/协议、有效请求选项和宿主语义版本；不能只比较 Observation 或可读日志投影。reasoning 的不透明原生材料若参与后续请求，也必须保留身份。

宿主诊断 ID 如不参与模型输入，可以与语义输入分开关联；角色、操作、工具回执等实际进入输入的身份不可为提高命中率而随意删除或归一化。首版应比较结构化原值/规范编码，哈希仅作索引，并能定位不匹配原因。

### 有限时域的影响包络

研究查询形状：在真实状态 S、模拟起点 t、有限时域 H 和声明的机制集合下，求一次行动或一组允许行动可能影响的对象/状态键，以及影响到达的最早时间下界。

这里的“空间”是语义关系图，包含地点、角色、共享资源和远程关系，不依赖坐标。须区分：

1. **直接效果**：行动直接修改的状态或投递的信息。
2. **规则连锁**：由这些变化触发的确定性或有声明范围的后续效果。
3. **后续自主决策**：接收者可选择任意被允许行动，其影响需要取并集或缩短预测范围。

未产生行动时取所有允许效果的保守并集；产生具体候选后可收窄；实际执行的影响只用于验证与测量，不能回头当作当初可知的保证。无限时域的全局人生影响不在本研究求解范围。

估计可以多算，不能把可能更早到达的影响排除。路径不存在需要机制覆盖依据；未知机制、动态拓扑或无法保证的跨域访问返回 unknown，退回输入验证/串行，不能把无记录当作无影响。

### 从影响包络到安全窗口

反向查询关注角色预计决策：谁可能在目标逻辑边界前改变其唤醒条件、可见材料或工具输入？最早外部到达边界只是必要条件，还要正确预测自身活动、身体、昼夜等已知演化。

窗口采用保守的半开边界；外部影响与唤醒同 tick 时，只有证明种类/逻辑顺序后才能纳入，否则缩短窗口或验证后再采用。到期、穿越作用域、拓扑/允许行动变化均需重算或失效，避免漏掉新进入范围的角色。

零时间影响可能连续传播，即时可达闭包可能很大。不能仅凭每一步一跳或单条边有界声称全局隔离。随机未来只有在规则已确定且预测可纯计算、不会推进共享随机游标时才可投影；其余视为不确定输入。

## 候选算法与最小实施路径

### A. 保持提交次序的提前推理

先选择少量容易构造预计输入的同刻/临近唤醒；每角色最多一个候选，总并发受限。由协调者完成输入冻结、预算预留、身份分配和顺序审计，工作者只取得独立输入并等待 Completion，不接触可变世界或共享 writer。

实际轮到角色时检查：运行分支/角色控制代次仍适用，目标唤醒仍有效，完整实际输入与预计输入一致，模型结果满足原有 Completed 与工具协议合同。随后才进入当前操作接收、领域校验和 E/S。行动仍合法不能替代输入相等；输入相等也不能替代当前世界的领域校验。

未知/失配则丢弃或尽力取消，按现有业务语义重新请求；取消不保证远端未计算，也不返还实际请求额度。候选错误可以留诊断，但不应仅因无关的过期候选失败就暂停当前合法行动；真正影响共享日志、凭据或预算的故障仍须协调者处理。

首个版本可以只缓存一次模型响应，不必提前执行整个工具循环。若响应是 feedback：确认候选有效后再保存反馈、返回真实回执并继续。无需世界回滚、预执行动作或伪造成功工具结果。

### B. 比较至少两种边界估计

- **粗粒度作用域/依赖闭包**：列明地点、即时连接、共享资源与远程关系；未知或连锁过宽时合并，作为容易核验的保守基线。
- **带最短延迟的传播**：在相同机制声明上累积传播时间下界，在 H 内截断；零延迟闭包、已排队到达事件、移动与共享状态访问均纳入。动态机制可以先不支持，明确退化。

两者使用相同允许行动和规则；不能让更精细方法通过忽略依赖获得优势。独立小模型枚举已允许的行动序列检验漏算，并审查本地传播合同的覆盖依据；有限样本通过不构成任意游戏的数学证明。

### C. 安全与投机的混合调度

比较 serial、仅安全窗口、固定小窗口投机，必要时再加入基于已测采用率的简单调整。若安全策略已退化为串行，保留这个结果，不人为放松正确性条件。

候选优先级可先按预计服务顺序；以模型快慢决定世界先后、无限生成后续分支、自动规划整个人生不在首版范围。只有证据显示固定策略明显浪费时，才增加调度复杂度。

### D. 隔离规则变体

原规则调度实验不修改玩法。传播延迟、作用范围或共享资源划分的变体在实验实例中显式选择、固定内容指纹，每个变体单独对照，不改变默认 Hillside 存档和动作合同。

Flags 继续表达连接能力。若试验需要传播延迟，使用独立参数或实验侧模型；不把事件类型、时间或并发策略塞进预留位。不为实验预建事件总线、订阅框架、通用 ECS 或自动依赖捕获框架。

## 最小工程边界

- 原型优先在实验工程与 Playground 应用接缝实现；新增最小 internal 接缝须有实际消费者和验证。不为白盒实验扩大跨仓 public API/IVT。
- 可对本仓做必要重构，没有旧开发 API 兼容包袱；不改默认玩法、默认并行模式或 schema/存档政策，不删除现场。确需突破这些边界时先形成具体方案交用户裁决。
- 领域 E/S 仍是恢复权威。候选是运行时可丢弃状态；冷开清空候选，pending E 只恢复已保存事实，不调用模型/Plan，不恢复 Task 或执行栈。
- speculative 请求、模型结果、采用/废弃原因可以作为研究诊断，但不能伪装成普通已发生决策，不能进入角色经历或自动记忆。优先复用主日志/raw 的职责；实验统计若独立，明确为非权威派生工件，避免建立第二份操作日志。
- 共享预算必须在并发启动前原子预留；顺序工具会话与独立请求的并发边界分开。反馈、呈现、日志和连接创建/释放须有明确所有者。
- Human 继续真实输入，不预测或代写人的操作；可在等待期间准备 LLM 候选，但本阶段不承诺消除 Human 对全局世界推进的阻塞。
- 首版不进行多 Kernel 并行提交、区域独立时钟、跨进程模拟、世界乐观回滚或跨文件事务。研究若发现这些方向必要，留下证据和后续课题。

## 前人经验与证据范围

1. [OMNeT++ 并行模拟手册，第 16 章](https://doc.omnetpp.org/omnetpp/manual/#cha:parallel-exec)：保守同步避免因果倒置，乐观同步允许检测后修复；本研究借鉴安全前瞻，首版不实现完整 Time Warp。
2. [cLinkDelayLookahead 官方 API](https://doc.omnetpp.org/omnetpp/parsim-api/classomnetpp_1_1cLinkDelayLookahead.html)：根据分区间最短连接延迟计算前瞻。它说明最短传播时间的用途，不证明现有游戏已具备这种合同。
3. [McGlohon / Carothers，2021](https://arxiv.org/abs/2105.00069)：同模拟时刻事件的确定性总序研究。当前核对作者摘要与元数据；后续引用具体算法前阅读正文，不能假定可直接替换本仓仲裁。

这些资料证明可借鉴的方法存在，不构成 DramaBoard 或当前模型端点的性能结论。后续文献调查针对具体假设限量开展，记录实际读到的证据与不适用之处，不以资料数量代替实验。
