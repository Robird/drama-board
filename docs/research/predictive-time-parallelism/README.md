# 预测式时间模型的角色推理并行研究

方案形成于 2026-11-02；2026-11-03 用户已启动自主研究 Goal。当前执行状态以[工作计划](work-plan.md)为准。实施起点为 DramaBoard `83dcc9e`（产品代码基线 `e5208cb`）；结果以新实验为依据。

## 研究目标

在保持角色信息边界和世界因果语义的前提下，探索能够降低有效角色决策等待时间的世界规则、影响范围估算方法与提前推理机制，用可复现实验证明收益、成本及适用边界，并留下研究文档和可运行代码。

主要成本是 LLM 调用的墙钟耗时。先研究**并行推理、按既有顺序确认与提交**，不以并行执行机械规则或改造持久化为前置条件。增加并发数本身不算成功；低交互密度下有效、密集交互下退化，乃至某条路线不值得采用，均可成为有证据的成果。

用户已接受的方向：有限作用范围、跨范围最短作用延迟、有界提前推理、实际采用前验证；这些是待实验的候选，不是必须证明正确或推广到全部玩法的结论。
