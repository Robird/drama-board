# 有限时域影响估计原型

2026-11-03。代码入口为 `experiments/PredictiveTimeParallelism/Influence/InfluenceExperiments.cs` 的 `InfluenceExperiments.Run()`。主线程已实际构建并执行：21,870 次查询、196,830 个保守性条件无失败；精确范围、工件和待解决问题见[首轮实验](initial-probe.md)。

## 两个估计共享的合同

节点代表语义状态键、观察/唤醒输入键或共享资源，不是地理坐标。每条有向边声明一次变化可能引起的后续变化，权重是**所有允许行动与规则分支的传播耗时下界**。角色再次自主决策的所有允许效果也必须在图中；未知行动不是忽略边的理由。已排队影响以带相对到达下界的 seed 输入。

图在整个查询时域内须覆盖所有可能新增关系。图代次只在调用方按所有拓扑/能力/作用域变化递增并在采用时重新比对才有意义；它不是自动依赖发现。未证明完整、动态关系不受覆盖或代次失配时，返回 `Unknown`、所有节点零下界，并拒绝发出安全证书。不能将未知解释为空集合。

粗粒度算法将边的传播下界全部降为零，再求依赖闭包；有限时域算法用非负边权的最短到达下界并在 H 截断。两者覆盖相同规则。初始已排队 seed 的时间偏移保留。反向查询从目标输入/唤醒键沿反向边传播，得到每个潜在外部来源的到达下界。零延迟环通过严格距离改善终止，绝不只取一跳。

保守性依据是：任何允许执行的因果链都映射为图中一条路径；实际每步耗时不小于对应权重，因此图最短路径不晚于该链实际到达。粗粒度再将权重减至零仍保守。此推导依赖机制覆盖，原型没有证明当前 Playground 满足该合同。

包络成员为下界不大于 H 的节点，`null` 仅表示所声明图中 H 内无可能到达下界，不能解释为永远不可达。`ProvesNoArrivalBefore` 仅接受时域内半开窗口，目标 tick 的影响不能据此证明目标输入安全；使用者还须排除同 tick 未证明的逻辑顺序，并处理自身确定演化、已知随机性、完整模型输入和最终采用验证。该原型没有给出可直接采用 LLM 候选的充分条件。

## 独立有限模型检验

`Run()` 枚举三个节点的全部 729 个无自环有向图：每条边有缺失、零下界、一 tick 下界三种取值；每图枚举所有三个起点及 H=0..4。每图再分别令实际边耗时等于下界或下界加一。独立 oracle 以 `(节点,tick)` 有限事件状态的穷举不动点传播，保留所有可达时间，使用实际边耗时；不调用最短路径、反向查询、估计包络或其剪枝。

每个实际可达目标同时检验粗粒度、有限时域及反向查询均不漏算且下界不晚；反向结果还与对应正向下界核对。返回汇总包括 oracle 成员数、两法成员数、假阳性成员数、延迟法排除的粗粒度成员数，分母是查询中的节点成员，不冒充实际应用收益。另有具名检查：共享资源零时延多跳及环、已排队到达、未知合同、拓扑代次失配、半开窗口。

检验覆盖有限图和指定耗时变体，不穷举任意规则程序、超边/联合前置条件、时变边或所有实际延迟赋值。图允许效果过度组合，可能产生现实不存在的路径，增加假阳性；这符合保守包络，但不能证明紧致。负权重直接拒绝。实现查询逐边扫描而非优化索引，没有性能或可扩展性主张。后续最小实验应把实际允许动作和共享机制映射为经审查的覆盖声明，再与当前 Playground 轨迹及新关系进入反例比较。
