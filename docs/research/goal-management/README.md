# 目标管理与行为预测：跨领域研究综合

日期：2026-10-31。四个独立研究工作包，主线程核对关键来源并整合。服务于[角色目标管理里程碑](../../design/goal-management/milestone.md)；本文记录设计建议与实验候选，研究本身未修改生产代码，后续采用情况见下段。

采用情况：用户认可后，目的/方法、完成标准、复查线索、信息型目标及相应反例已纳入[设计草案](../../design/goal-management/design.md)和[用户故事](../../design/goal-management/user-stories.md)。下文保留研究时的建议与证据边界；当前设计取舍以专题草案为准，不表示所有研究候选均获采用或已实施。

## 1. 先区分我们在解决什么

| 问题 | 在游戏中的例子 | 可用的权威与边界 |
| --- | --- | --- |
| 管理自己的目标 | 我已答应送两份水，暂时先避寒 | 角色显式采纳的意图；由目标操作保存，不靠推测重建 |
| 选择实现办法 | 采水、接受赠物、改换路线 | 基于角色可知信息的决策，仍由游戏校验行动 |
| 判断他人目标 | 他去溪流是补水、找人还是路过 | 观察与声明支持的假设，不能读取他人的私有 Goal 补齐答案 |
| 预测后续行为 | 他是否会按约定来到溪流湾 | 条件性预测，目标、知识、资源、临时需求都可能影响行动 |
| 预测规则过程 | 当前移动预计何时到达 | 现有时间/空间引擎的规则预测；不能与上一行的意图推断混为同一个机制 |

这些领域共同提醒我们：目的、办法、已发生事实和对未来的判断需要分开。已有 Goal／GoalLink／Focus／Activity 边界可以承接大部分收益，首版不需要完整认知架构。

## 2. 四个视角的主要收获

| 视角与独立报告 | 有价值的成果 | 对当前设计的启发 | 不直接移植的部分 |
| --- | --- | --- | --- |
| [军事决策](military.md) | 指挥意图、关键假设检查、行动与效果评估 | 保留目的与成功条件，允许改办法；区分历史完成和当前有效 | 指挥层级、全量分支计划、参谋流程 |
| [商业协作](business.md) | 成果与工作分离、可见的未完工作、检查与适应 | Paused 仍可见且占材料容量；无变化不反复改写；避免目标数量 KPI | 固定 Sprint、绩效排名、用目标数冒充真实负荷 |
| [刑侦与情报分析](investigation.md) | 区分来源与判断、竞争解释、寻找区分性证据 | 信息获取可成为子目标；挂起/修订有依据；允许“尚不确定” | 画像评分、每轮分析矩阵、把推测写成他人真实意图 |
| [AI 规划与目标识别](ai-planning.md) | BDI 的承诺与重审、HTN 的过程语义、概率目标识别 | Focus 不代表全部承诺；结果目标与过程目标不同；行动交错不等于放弃 | 自动 HTN 规划器、计划库穷举、未经校准的概率输出 |

军事的目的导向可见 ADP 6-0（2019）§1-45～1-51；商业的目标与具体工作分离可见 [Scrum Guide 2020 的 Sprint Goal](https://scrumguides.org/scrum-guide.html#sprint-backlog)。这些是原领域规范性方法，并非 LLM 效果证据；详细军方来源与取得限制见独立报告。

[Rao 与 Georgeff（1995）](https://cdn.aaai.org/ICMAS/1995/ICMAS95-042.pdf)提供更直接的 agent 架构依据：承诺使既有决定持续存在，重新考虑则应与变化和代价相匹配。本游戏在控制器决策期间暂停模型时间，因此论文中的实时计算压力不能照搬；这里主要衡量调用成本、材料大小和决策反复。

## 3. 建议首版吸收的五点

### 3.1 保持目的，允许更换办法

目标材料同时回答“想要什么结果”和“现在准备怎么做”。资源点耗尽可以使采水方法失效，但不自动取消赠水承诺。重要约定被修订时留下简短理由；没有变化就直接行动，不为了形式上的维护每回合调用 update。

大部分内容已有字段可表达；不必新增 Intent/Strategy 类型。父子关联继续表示来源理由，不升级成前置依赖、执行顺序或自动成果分摊。

### 3.2 完成标准需要说明是在谈结果、过程还是持续条件

“获得两份水”和“亲自采集两份水”有不同的达成办法；[UMCP 原始论文的 HTN 语义](https://www.cs.umd.edu/~nau/papers/erol1994umcp.pdf)对此类结果任务与复合过程作了明确区分。我们借鉴其区分，不继承规划算法。

另一个独立维度是有效时间：“曾经采到四份水”与“现在有足够水到达出口”不同。ADP 5-0（2019）§5-13～5-19 对行动执行与效果状态的区分也支持这一检查问题。模型喝掉水之后，历史采集成果不应被抹掉，当前补给条件则需要重新评估。[ADP 5-0 原文](https://rdl.train.army.mil/catalog-ws/view/100.ATSC/E4166A5D-0FE7-4780-916A-A7E9B227147C-1337689957702/adp5_0.pdf)

建议先写进完成标准与测试，不急着增加目标类型枚举。**首版可试的默认政策**是保留一次性 Completed 记录，需要再次取得成果时另建目标；修改错误判断、持续目标的重开政策仍需设计裁决。该建议不代表已选定禁止重开。

### 3.3 保存关键假设和“何时重看”，不要求完整推理记录

可以在已有正文/恢复线索中写：`待核实：渡口仍开放；如果关闭，重新选择出口路线。` Open 目标同样可能需要这种线索，不仅 Paused 才有条件依赖。

来源中的假设检查和未来迹象，适合转化为短提示。首版由控制器读取新观察后判断；自动事件订阅、提醒状态和条件表达式继续延期。重看并不自动意味着切焦点、恢复目标或取消 Activity。

### 3.4 把获取信息本身当作可以完成的工作

`核实渡口是否开放`得到“关闭”的可靠信息，也可以完成；`经渡口返回社会`却因此需要改方法。共享这项调查的多个父目标都能使用其结果，但不能因此全被判为完成。

这直接回应 GoalLink 的复用需求，不必新建 InvestigationTask。对复杂推测，保留一个相关替代解释及下一项区分性观察，比无条件增加支持材料更有用。这是对 [Heuer，ACH 第 8 章](https://www.cia.gov/resources/csi/static/Pyschology-of-Intelligence-Analysis.pdf)的轻量设计迁移，不声称一条提示就能消除偏见。

### 3.5 挂起不是遗忘，材料容量不是绩效指标

Open 与 Paused 都占未结束材料额度，按目标身份计数，关联另计。这里借鉴 [Kanban Guide 2025.5](https://kanbanguides.org/the-kanban-guide/2025.5/)的可见性与容量意识，但不把所有父子目标都称作已开工 WIP，也不把 Focus 数量当作责任总量。

验收看真实交付、逃离结果、承诺遗漏和管理成本；不按关闭目标数、拆分数量、编辑频率奖励模型。已结束数量高可能只是拆得更碎。目标信息也不能挤掉身体危险和当前活动。

## 4. 对行为预测的额外边界

[ICD 203，D.6.e](https://www.dni.gov/files/documents/ICD/ICD-203.pdf)区分来源、假设、判断，以及发生可能性与判断依据的可信程度。游戏可以保存“阿青说会来”，角色可以推测“阿青可能在途中”，但不能因此建立“阿青当前就在途中”的世界事实。

[Ramírez 与 Geffner（2010）](https://ojs.aaai.org/index.php/AAAI/article/view/7745)展示了如何用行动观察对候选目标排序，但其确定动作效果、已知初态与给定候选集等假设比当前角色视角强。[PHATT（2009）](https://rpgoldman.goldman-tribe.org/papers/phatt-aij-2009.pdf)处理交错目标的执行解释，但一般漏观测、状态和失败扩展有明显复杂度。两者不能直接证明任意 LLM 的下一步可可靠预测。

因此首版只需允许未知和多种解释。将来开展预测实验时，分别评估“猜测最终目标”和“预测下一步行动”；看见绕路不能直接判定放弃，没看见赠物不能直接判定没有赠物。宿主可用隐藏脚本目标/已记录 Goal 和实际动作作受限标签，但不得注入被评测角色的材料；声明的 Goal 也不保证穷尽真实动机。

## 5. 最有区分力的实验组合

| 实验 | 对应故事 | 观察点 |
| --- | --- | --- |
| 原水源失效，另有可行补水办法 | US-01、US-04 | 是否保留约定、改换方法；相关信息与判断无变化时是否停止反复整理 |
| 采集完成后消耗库存 | US-05、US-06 | 是否把历史成果误当当前补给充足；是否恰当保留历史并安排新补给 |
| 低温临时打断 | US-02 | 是否切换后返回，目标编辑是否保持 Activity；是否陷入永远整理目标 |
| 两个目的共享“核实渡口” | US-03、EX-01 | 得到否定答案能否结束调查；上层目的是否仍保留 |
| 会合对象暂时缺席 | US-04、EX-05 | 是否保留迟到/改约等解释，得到新消息后能否修订；是否承认信息不足 |

这里对既有故事作实验细化，不把全部新场景加入本轮必做范围。早期先选一个“跨回合兑现＋方法失效”和一个“共享调查＋否定答案”场景；身体中断及恢复边界继续沿里程碑验收。

比较 handoff 基线、目标材料、目标材料加短复查提示时，应固定可控制的初态和脚本干预，保留多次模型运行。记录遗漏、误标完成、不必要切换、管理调用/材料长度及游戏结果。出现自然语言交互时还需说明措辞与时机差异；单局成功只能提供可行性证据，不能证明因果或一般可靠性。本轮未执行这些实验。

## 6. 本轮证据与仍待裁决的问题

四组报告分别写独立文件；主线程独立读取 Scrum、Kanban、BDI、UMCP、PHATT、概率目标识别及 CIA/ODNI 的关键原文，并复现 ADP 5-0 官方索引中的指定段落。修正了将 Focus 过窄表述为“当前方法”的术语问题；交叉审阅进一步修正了“只有新证据才允许修订目标”的过强限制。

部分军方 PDF 直读超时，仅取得官方索引的指定段落；部分警务学院页面直读 403，由官方检索正文及官方 PDF 交叉核验。各报告记录版本和取得范围，不宣称获得最新完整教范或法律规范。商业批判文献使用作者机构摘要，不能作为新实证试验。研究没有新增游戏能力、运行模型试玩或替代既有验收。

原先的容量数值、关联清理、焦点回退、结束后重开和命令原子形状仍待裁决。这些资料主要改善完成标准、复议提示与实验质量，不能替我们选择唯一正确的产品规则。下一轮可以据此完善设计合同，再开始实现；无需先增加完整 BDI、HTN、证据图谱或行为预测引擎。
