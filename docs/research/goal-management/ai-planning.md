# AI 规划与目标识别：保持承诺，谨慎解释行动

日期：2026-10-31。这是面向[目标管理设计](../../design/goal-management/design.md)的研究建议，不是新增实施承诺。结论是先借鉴意图持久性与重审纪律，保留 Goal／GoalLink／Focus 的轻量边界；自动规划与他人意图识别仍延期。

## 1. BDI：目标应稳定，但方法可以重新考虑

Rao 与 Georgeff 的 [BDI Agents: From Theory to Practice](https://cdn.aaai.org/ICMAS/1995/ICMAS95-042.pdf#page=3)（1995），pp. 314–317，特别是 “Dynamic Constraints” 与 “Abstract Architecture”，讨论了动态环境中的两难：反复从头选择行动代价大，无条件坚持旧方案又会失败。其意图表示保存已作出的选择；承诺策略规定何时维持、何时放弃。理论依赖可识别的重要变化与相应信念模型，实用系统又主动限制表示能力，并非一个能替任意 LLM 保证理性的定理。

**本项目借用**：Goal 保存已采纳事项，Focus 只决定当前展开什么，不能把离开焦点解释为撤销承诺。GoalLink 保存当前方法服务的上层目的；方法失败时先审查该方法，避免顺带放弃上层目的。已有“进展／下一步／挂起原因／恢复线索”可承载这些信息，无需立即增加完整 BDI 类型系统。

**首版**：在操作指引与试玩中提示“有相关信息或判断变化时修订重要约定，并记录简短原因；无变化不反复改写”。重新理解已有信息、发现计划错误或明确改变偏好，也可能构成合理的修订理由；不要每次换 Context 都强制改写目标。**延期**：自动相关事件订阅、逻辑一致性证明及自动终止条件。我们暂停世界等待控制器，原论文的实时环境计算压力不能原样迁移；这里更直接的代价是调用数、材料膨胀和计划反复。

**实验**：封路后改走替代路线，“返回社会”仍保留；无关天气提示连续到来时，不应反复新建同义目标。记录成功率、无必要编辑次数和旧承诺遗漏，而非只统计目标数量。

## 2. HTN：结果、过程、分解方法是不同东西

Erol、Hendler 与 Nau 的 [UMCP: A Sound and Complete Procedure for Hierarchical Task-Network Planning](https://www.cs.umd.edu/~nau/papers/erol1994umcp.pdf#page=1)（1994），pp. 249–250 的 “HTN planning” 区分结果任务、原子动作和复合任务：例如“拥有房屋”不同于“建造房屋”。任务网络还含顺序、绑定和状态约束，方法将复合任务分解为网络。pp. 253 的正确性结果建立在这些形式语义及算法约束上。

**本项目借用**：完成标准必须说清要求的是结果还是特定过程。“获得两份水”可以通过赠与完成，“亲自采集两份水”不行；“探索地标”与“从同伴处获知地标”也未必等价。标题相同不能确定身份相同，更不能自动合并消耗性需求。

GoalLink 当前只说“为什么需要这个子目标”，没有 HTN 的执行顺序、分解方法或资源保护语义。**不能因为图长得像任务网络，就宣传自动生成可执行计划、子项全完父项自动完成，或共享一次采集就满足两份需求。** Focus 路径同样不是执行栈。

**首版**：改善完成标准与共享示例，执行仍走已有合法行动校验。**延期**：只有真实场景要求自动规划时，另建有前提和动作效果的受限方法库。**实验**：角色收到赠水后，结果型目标可由角色判为完成，亲采型目标仍未完成；共享“确认地标位置”完成后，补给和会合父目标仍各有剩余工作。

## 3. 目标识别：保留多个解释，不把绕路当作变心

Ramírez 与 Geffner 的 [Probabilistic Plan Recognition Using Off-the-Shelf Classical Planners](https://ojs.aaai.org/index.php/AAAI/article/view/7745)（2010），[论文 pp. 1121–1122](https://ojs.aaai.org/index.php/AAAI/article/download/7745/7605)，用符合／不符合观察的计划成本差估计候选目标概率。其 “Noisy Walk” 示例展示了非最短路径行为：严格最优解释会排除全部候选，概率形式则保留并排序。假设包括已给定候选目标及先验、确定动作效果、双方完整知道初态；部分行动可未被观察，不等于允许任意未知世界。

**本项目借用**：将自己的已采纳 Goal 与“猜测阿青要做什么”隔离。看见阿青朝溪流走，只能支持补水、会合、路过等候选；后来绕路，可能是在避险，不足以证明违约。若未来保存这种判断，应附观察依据、候选解释和未确定项，不能直接写进对方的真实 Goal。

**首版**不实现数值概率或识别器，只约束文本和实验判据；未经校准的百分比会制造精确错觉。**延期**到需要合作预判时，可在小地图、有限目标集合上比较候选排序。不能把当前 LLM 当作固定代价函数下的近最优规划器，也不能以私有地图、背包补齐其“完整初态”。

**实验**：同一段去溪流的路线分别服务补水和会合，观察者应承认歧义；加入寒冷绕路后，仍保留原目标候选。衡量过早确定率与后续修正，而非只看最后猜中。

## 4. PHATT：行动交错与看不见，都是解释模型的一部分

Geib 与 Goldman 的 [A probabilistic plan recognition algorithm based on plan tree grammars](https://rpgoldman.goldman-tribe.org/papers/phatt-aij-2009.pdf#page=2)（2009），§1、§4–8 以执行模型与可执行下一步集合解释多个交错目标和部分有序计划，依赖计划库及概率参数，且排除主动欺骗。尤其要读 §12、pp. 1129–1130：一般部分可观测、状态影响与失败处理仍有扩展难题；核心轨迹假设与理论上的观察模型扩展不能混为实现保证。

**本项目借用**：角色去取水途中吃东西，不必解释成取消取水；没看见赠物，也不等于确定没赠。自己的 Focus 切换轨迹可供宿主诊断，角色对别人的判断只能使用其实际感知。**首版**保留非焦点目标和挂起线索；**延期**计划库、隐含行动枚举与自动放弃检测，避免为了预测把所有可能世界装进目标管理模块。

**实验**：一人同时补给和找人，行动交错；另一人短暂离场错过赠与。评测应区分“未观察”“观察到未发生”与“已经验证发生”，允许未知回答。

## 5. 实施取舍与评测边界

最小收益不是增加更多字段，而是落实三条纪律：**已采纳目标持续可见；方法受挫时重新审查而不静默遗忘；角色判断与世界事实分开。** 先用现有字段和 US-01～03 测试，再决定是否增加结构化失效条件。

宿主可以读取角色实际记录的 Goal、操作和世界事件作评测标签，但不能把他人的私有目标注入角色 Context。Goal 记录本身也只是明确声明的意图，不保证涵盖该角色全部动机；预测下一步行动与识别最终目标应分别评分。工程持久性、模型合理性和行为预测准确性是三个验收面，不能互相代替。

尚待裁决：完成目标后成果失效应重开还是另建；共享成果的有效性由谁复核；目标编辑对模型的真实调用负担。上述论文提供区分概念的工具，没有替本项目确定这些产品规则。
