# 角色地图知识与导航

状态：2026-11-03 设计阶段，尚未实施。本文组用于后续 Codex Goal 迭代；本轮只编写与审议文档，不启动 Goal。

最小模型：**每个角色保存自己的空间知识，用已知连接求路，保存一份候选路径与一份活动导航计划，按现有移动规则逐段走，每到中间点由角色确认继续。未走通的通道只暴露本端入口。**

## 范围与自主决策边界

本阶段消费者只有 Playground 的角色、Console、LLM 适配和既有历史/恢复/预取。先在 Playground 组合，Spatial 保留客观运动；不新增通用导航程序集、世界事件框架或宿主地图缓存。

静态拓扑、公开固定行程成本是首版边界；动态道路/传闻/地图分享/坐标启发式/自动重规划/不停站模式/并行制造延期。静态信息之外的远方动态状态不得透传给角色，实际出发仍校验当前世界。

命令名、内部类型、合理材料上限及测试组织可由实施代理自主决定并同步文档。改变逐站确认、允许未知捷径、自动共享知识、移除同版本恢复或扩大远方实时可见性属于产品语义变化，不得作为“简化”暗中实施。
