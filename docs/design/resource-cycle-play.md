> 2026-10-27。用户已选择就地增强 `src/ResourceCycle`，同时独立研究预测对象核心重构。本片不增加移动，不依赖该重构完成。
> 历史单角色切片：当前实现已采用[多人有限采集规则](resource-cycle-multiplayer-gathering.md)，本文的即时采集与单株成熟机制不再描述现行玩法。

## 目标和范围

将已有昼夜/资源实验变成一个可实际操作的小场景：单角色、单地点、太阳花、月光草、背包、等待、采集。复用现有库、CLI 和单根持久化链路，不新建另一套 DemoWorld 或应用项目。

Console 是输入渠道，游戏角色是世界对象。未来一个 Human 可以轮流控制多个角色：某角色获得决策权时暂停世界、显示其观察、等待合法操作。本片只创建一个角色，不提前实现多人竞争或轮转策略，但接口显式传递角色身份。

原程序化销毁实验保留为批处理模式，供预测增量/全量对照。新 `--play` 模式使用无销毁脚本的世界，避免玩家采集体验受到隐藏脚本干扰。两种模式的存档不能误用。

## 本片规则

- 起始时刻 D0 16:00。太阳花需要累计白天 3 小时，月光草需要累计夜晚 4 小时；不合光照时暂停并保留进度，成熟后保持直到采集。
- `gather sunflower` / `gather moongrass`：只接受成熟植物，即时采集一份同名物品；植物清零并开始下一轮生长。资源重置与背包增加由同一组事实发布，不能重复领取。
- `wait N`：N 是 1–24 的整数小时。先发布等待开始，创建完成预测；期间自然事件照常执行，等待完成后才重新请求玩家决策。
- 同刻先处理自然变化，再处理等待完成，最后请求决策。继承资源实验内部成熟→光照→脚本的顺序；可玩模式没有脚本条目。
- `look`、`help`、非法输入均不产生世界 occurrence，不消耗时间。`quit` / EOF 正常退出；Ctrl+C 取消本次交互。
- 第一片只做完整 Markdown，不移植 delta、矩阵压缩、任务/NPC 或事件因果框架。

即时采集不会创造无限零耗时循环：每株植物采一次即不成熟。未来增加可重复的即时动作时，需要另定耗时/循环边界，不能依赖放宽 Kernel 同刻转换上限。

## 状态与发布

`CycleWorld` 增加可选角色子图；无角色仍为原批处理实验。角色拥有稳定 ID、独立背包、等待结束时刻、决策 generation 和最近行动结果。持久对象仍采用不可变替换，生成事实后由纯 Fold 应用；旧世界快照不可原位修改。

决策来源是运行时接口，不序列化 Console、delegate 或 Task。它在当前已提交时刻被选中的决策候选中等待输入，返回行动意图；公共校验用于 UI 反馈，规划在提交前再次检查。决策候选键包含 generation，接受动作后消费旧请求。

所有业务世界和角色子图仍通过一个 `CycleDurableRoot` 发布。`CycleWorld` 是包含 Business 与 Forecasts 的运行时包装，预测和固定订阅不落盘。等待中的输入尚未形成 E，重开重新询问；已保存 E 则补 Fold → 纯 Complete → S，不再调用输入者。若世界已处于等待中，重开先继续执行该行动与期间自然事件，到完成后才重新询问。

没有旧档兼容要求；当前已接入[运行时缓存完成边界](runtime-derived-predictions.md#9-resourcecycle-单角色迁移)，没有建立第二套通用调度框架。多角色可独立扩展业务身份、行动与轮转规则，不是缓存拆分的前置条件。

## 观察

完整文本包含当前地点、角色、时刻/昼夜、两种植物的生长条件和有效进度、成熟状态、背包、命令语法与当前阻塞原因。输入提示明确“轮到哪个角色”。等待期间发生的自然事件和行动结果按已提交顺序输出。

开发诊断保留预测和订阅信息，与玩家观察分离；不把待失效的预测时间称为必然成熟时间。重复观察不执行规则，也不伪造过去事件。

## 验收目标

1. 从 D0 16:00 等待 6 小时：太阳花停在 2/3，月光草在 22:00 成熟；采集后背包为一份月光草。
2. 再等待 9 小时至 D1 07:00：月光草再次成熟，太阳花恢复并成熟；各可采一次。等待完成与自然事件同刻时观察已反映自然结果。
3. 未成熟采集、格式错误、查询、等待输入与输入取消不提交；旧快照不变。
4. 增量与全量模式产生相同状态/事实；输入脚本不依赖开发诊断。
5. 等待途中冷开、采集和等待 E-only 中断后恢复，与连续执行一致；不重复发物品、不重复询问已记录行动。
6. 真实 CLI 的退出、EOF、冷开续玩和模式误用有可观察结果；原批处理实验继续通过。

最终运行证据另见实施验收文档，不将本节目标当作已通过结果。
