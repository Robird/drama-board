# 目标容量、保留与 Context 投影

状态：2026-10-31，容量规则与当前材料投影已实现，完成工程验证及规模量测。本文补充[领域设计](design.md)，操作入口见[操作合同](operations.md)；量测与实际运行证据集中在[工程验收](../../experiments/goal-management-acceptance.md)及[试玩记录](../../experiments/goal-management-playtest.md)。数字是可调整的原型默认值，不能当成真实模型实验结论。

## 1. 当前目标集合的界限

按角色分别限制，计数按身份而非标题或引用次数：

| 项目 | 首版默认上限 |
| --- | ---: |
| 未结束 Goal（Open + Paused） | 12 |
| 所有保留 Goal（含已结束） | 32 |
| GoalLink | 48 |
| 每个 Goal 的敏感修订 | 最近 3 条 |
| 默认最近结束摘要 | 3 个 Goal |
| 完整当前材料中的目标操作回执 | 最近 3 条已保留目标操作，包含成功及拒绝 |

文本按 Unicode scalar 计数，拒绝无效 Unicode；ID、字段名、序号不占文本额度：

| 字段 | 上限 | 空值规则 |
| --- | ---: | --- |
| title（标题/目的简述） | 80 | 必填、非空白 |
| criteria（完成标准） | 240 | 必填、非空白 |
| progress（进展/依据） | 320 | 可空 |
| nextStep（下一步/方法） | 160 | 可空 |
| revisit（复查线索） | 160 | 可空；独立字段，Open/Paused 目录均直接展示 |
| pauseReason / endNote | 各 240 | 仅相应状态有值且必填；其他状态为空 |
| GoalLink.reason | 160 | 必填、非空白 |
| 敏感修订 reason | 160 | 必填、非空白 |

可选正文清空后规范化为空；不保存空白字符串。状态和字段约束始终检查；未结束的 Paused 使用 pauseReason，Completed/Abandoned 使用 endNote，Open 两者均空。resume 清除 pauseReason，finish 替换为 endNote，reopen 清除 endNote。

一次敏感修订保留原标题、标准、结束说明、状态、修订原因和 `(ContextSequence, OperationSequence)`；该序号对在角色内确定顺序，不能只用每个 Context 都从头计数的 OperationSequence。一次提交产生至多一条修订。修订环满时只裁掉最旧修订，反馈说明有限保留；不拒绝本次更正、不删除目标。

这些限制约束当前业务根中的目标集合，不限制整份 E/S 历史、全部冻结观察或整个模型输入。当前字段粗上界为 `32 × (1200 + 3 × 720) + 48 × 160 = 115200` scalar，不含元数据和历史快照；这是保守数据规模计算，不是 token 数或内存字节数。实现应在同一默认策略处集中这些常量，测试和帮助由同源值读取；首版无需可热变更配置、通用配额服务或迁移注册表。

## 2. 显式清理与可达性

最近结束窗口只影响展示，绝不按年龄静默删除记录。只要 Goal 仍在集合里，详情就可读；任何 GoalLink 两端必须存在。未结束父目标引用的旧 Completed 调查始终有原结论，退出最近 3 个窗口不影响它。

首版不做自动垃圾回收或递归摘要。`forget` 仅允许删除**已结束且没有任何入边/出边**的 Goal。仍有关联时拒绝，列出阻碍的 Link ID 与解绑方式；只有显式 `unlink` 才移除来源理由，不暗中级联。forget 不删除已经冻结的历史材料、不复用 Goal ID，也不是删除存档历史的隐私擦除接口。

容量检查针对结果集合，失败完整拒绝。finish 在原记录上变状态，不分配第二个归档槽；满额仍能 finish/abandon、unlink、forget 或缩短正文。reopen 会占未结束额度，不能以“老 ID”绕过限额。

清理没有结构死锁：集合和关联有限，unlink 不受 Goal 满额限制且允许任意端点状态，全部关联都能逐条显式移除；已结束孤立目标随即可 forget。未结束事项必须先由角色决定结束，不以容量压力替角色放弃承诺。代价是可能需要多次清理操作；先测这项成本，不前置批量删除或自动淘汰。ID/序号溢出及宿主调用预算仍是独立边界，不承诺无限运行。

## 3. 默认展示与单目标详情

默认目标区从同一冻结快照产生：

- 标明“角色自述，当前库存与危险以世界观察为准”；显示使用额度及清理/查询入口。
- Focus 详细字段、选定来源路径及各祖先状态/关联理由；没有焦点时明确为空，不代选。
- 所有未结束目标的完整有界目录，至少含 ID、状态、标题、已有 revisit，以及 Paused 的原因。有父关联时附全部直接父 Goal ID 作为来源提示（理由可查看详情）；没有则标为独立目标。焦点不在目录重复全文，但仍计数。
- 焦点的直接父来源与直接子目标摘要；已结束子目标显示 endNote，不能只剩 Completed 标签。其他父目标可经 show 查看其直连结论，不递归展开整图。
- 最近结束按最近一次 finish 的序号对降序展示 3 个，ID 作稳定并列次序；reopen 后退出该窗口，说明勘误不伪造新的完成时间。与前面已展示内容去重。

单目标 show 展开全部当前字段、直接父/子关联及短结论、最近 3 条敏感修订；不递归遍历全部后代。目录 show 列出所有保留目标的 ID/状态/标题及全部 Link 的 ID/端点，便于找到旧记录、清理或补充来源；不列所有目标长正文。排序固定使用 ID 创建顺序，Focus 路径按指定顺序。

正文以数据安全方式渲染，换行、引号、代码围栏和终端控制字符不能成为宿主指令或新文档结构；沿用现有数据文字转义边界，不将文字拼入可执行命令。

## 4. 当前材料一次投影，历史仍冻结

当前实现：[CharacterContextRenderer](../../../src/ResourceCycle.Cli/CharacterContextRenderer.cs) 保留 Opening 与有序 Items 的一般材料，通过 [GoalView](../../../src/ResourceCycle.Cli/GoalView.cs) 单次投影当前目标、有限回执及有效查询；[RetainItems](../../../src/ResourceCycle/CycleInteractionRules.cs) 仍只裁近期范围外的拒绝，成功 Item 保留。显示裁剪不等于持久历史回收。

首版对新增目标类别采用下面的局部投影，不改其他经历/警告/交流的保留规则：

1. 观察持有当时的不可变目标快照，操作 Item 保存权威操作种类、相关 ID、短反馈及是否确实改变目标集合。旧观察不能引用会被原地修改的业务对象；不可变实例可共享，编辑后替换实例。
2. 完整当前输入只输出一次指定材料边界的最新默认目标区，不从 Opening 和每条旧 Item 反复展开目标全文。边界是该冻结 Context 的末尾；测试历史前缀时用明确的截止序号，不将 `afterItemSequence` 后缀过滤误当截止。
3. 最多显示最近 3 条保留目标操作的短回执，含操作序号、相关 ID、成功/拒绝/无变化、变更字段或可纠正的错误。长 RawInput 与旧正文仍精确保存在 Item/E/S，标准输入不逐次回显；目标专属 Effects 的旧/新正文也不另走通用渲染重复输出。语法错误若无法可靠归为目标命令，仍按现有拒绝呈现，不猜解析意图。
4. 最近一次**成功** show 的展开内容从其 Item 的冻结快照产生，标明所查 ID（或整理目录）及操作序号。其后无实际目标变化则继续显示；任何 Goal、关联、Focus 或修订记录变化均使其失效，显示简短“详情已过期，可重查”。拒绝、show 和真正 no-op 不使其失效。失效后不退回更老的查询；失败 show 不取代上次成功 show。发生变化后再改回原值也不会复活旧详情。
5. show 的来源仍是已有成功 Item，不新增持久详情槽或额外视图游标。回执展示窗口不裁剪成功 Item，因此 show 后多次无变化操作仍能重建详情。新 Context 不带入旧 show，但新的默认目录照常完整呈现。

上述当前目标、回执、最近成功 show 和它之后的变化都只在同一个 Context 截止前缀内选择，不能从前缀之外偷看后续操作。是否 Changed 来自权威规划并由事件应用校验，不能由调用方自报或依赖引用相等；S 冷开与 E-only 恢复必须投影同样结果。目标状态权威仍是角色私有集合，冻结观察是历史材料，两者不是独立可编辑副本。

Console append/delta 继续输出新发生的变化与回执，已打印的旧文字不擦除；查询失效必须有显式提示。full 和纯模型输入使用同一边界的默认区、回执及查询内容。重绘旧 Context 时使用那个 Context 的快照；不能因为今天 forget 或改标准而改写昨天。增量游标只决定发送哪些已有材料，不管理目标身份或语义。

## 5. 预算验证与重开条件

本方案防止目标长全文按成功操作次数重复进入完整输入，并未给 Context 成功 Items 或磁盘日志建立新的全局容量。当前同刻转换护栏、调用预算和换 Context 规则仍有效；长期存储裁剪只有在实际规模证据下另开，不以 UI 隐藏宣称回收。

当前 [LlmControllerOptions](../../../src/ResourceCycle.Completion/LlmControllerOptions.cs) 的默认完整输入门槛是 200000 UTF-16 code units，不是 token 预算；超限会暂停，不能删未结束事项、警告或合法操作来假装成功。目标字段上限不能保证整份 Context 永不超限。

施工须用最大合法图、最长 Focus 路径、高度共享、非 BMP Unicode 与需要转义的文本实际渲染量测；确保单次默认区、一个 show、3 条回执及典型世界材料在默认宿主预算内。连续 show/编辑应验证完整输入不重复所有目标全文，详情失效、警告保留和重开一致。若不满足，先降低这些原型默认量或缩减重复呈现，再记录取舍；不能用静默截断未结束目录过关。目录可读性、数字最优值和 Human 的清理成本留给真实试用，不阻塞以这些默认值施工。
