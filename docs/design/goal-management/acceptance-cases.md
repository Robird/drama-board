# 目标管理合同验收用例

状态：2026-10-31，设计审查产物，尚未转换为生产测试或实际运行证据。行为权威见[设计](design.md)；本文列出实施时必须覆盖的反例，不替代[用户故事](user-stories.md)的真实模型验收。

## 状态、来源与焦点

| 输入情境 | 预期结果 |
| --- | --- |
| A→C、B→C，Focus=A→C，暂停 A | C 和 B 不变；Focus 保留，路径将 A 标为 Paused |
| 同一共享 C 被暂停，A 为 Open | 两处均看到 C 为 Paused；Focus 从 A→C 回退 A，不跳 B |
| A(Open)→B(Paused)→C(Open)，完成 C | Focus 回退 A；B 不变 |
| A、B 均已结束，Focus=A→B→C，暂停 C | 清空 Focus；C 仍在未结束目录 |
| Focus=A→B→C，unlink A→B | 保留 B→C，不选择其他来源 |
| Focus=A→B→C，unlink B→C | 保留 [C]，不撤销活动 |
| C 有多个父来源，focus C 未提供路径 | 确定为 [C]；无隐式选择 |
| 显式路径缺边、末端不是指定目标或末端非 Open | 完整拒绝，旧 Focus 不变 |
| 完成独立临时目标 D，之前曾聚焦无关 C | 不恢复隐藏焦点栈；C 仍可见，可显式 focus C |
| 同一父子对重复 link、成环或引用别的角色 ID | 拒绝且不产生关联或部分变更；不泄露他人目标内容 |

## 更正与留痕

| 输入情境 | 预期结果 |
| --- | --- |
| 确实取得两份水，完成目标后喝掉 | 保留原 Completed；再次需要时另建目标 |
| 未赠水却误标 Completed | reopen 同一 ID，保留原判断及理由，清空当前结束说明；不修改库存 |
| 已放弃后重新愿意追求 | reopen；不抹掉保留范围内的放弃判断，不自动聚焦 |
| 已结束说明笔误，判断未变 | update 结束说明并附理由，留旧值；不改变状态、不占未结束名额 |
| 对 Completed 直接改标准或目的 | 拒绝；需先 reopen，再显式修订 |
| 同次修改标题及标准 | 一条敏感修订保存修改前原值；无半次更新 |
| 连续四次敏感修订 | 仅保留最近三次；查看明确说明有限保留，不承诺早期判断仍在 |
| 未结束额度已满时 reopen | 状态、修订记录、Focus、ID 分配均不变 |
| 对 Paused 再 pause，对 Completed 再 finish | 明确拒绝，不能追加虚假修订或结束记录 |
| 敏感修订 E 已发布、S 未发布就中断 | 恢复只应用原修订一次，不重新询问模型或追加第二条记录 |
| 采集中且有警告时编辑目标或 Focus | 活动期限、库存、身体、待响应警告和既有预算保持；允许记录必要交互元数据 |

## 容量与清理

| 输入情境 | 预期结果 |
| --- | --- |
| 两个 Open 父目标引用旧 Completed 调查，已有更多近期结束事项 | 两边 show 都能读取旧结论；近期窗口不删存储 |
| 非焦点未结束目标被多个父目标引用 | 默认目录显示全部直接父 ID，不因未展开详情而隐藏共享来源；理由可通过 show 读取 |
| unlink 一方后 forget 共享子目标 | 另一关联仍在则拒绝，列出阻碍 Link ID |
| Goal/Link 总额度及未结束额度同时满 | 可 finish、unlink、forget 后 create；不要求额外归档槽，不默默丢承诺 |
| 把 Open 全改 Paused | 未结束用量不变，不产生额外创建额度 |
| forget 后新建，或 E-only 边界恢复删除/新建 | 身份不复用，清理不重复，不修改旧快照 |
| 字段刚到上限/超一 scalar，含非 BMP 字符与转义 | 精确计数或拒绝；不以 UTF-16 code unit 数冒充 scalar |
| 最大合法图、最长来源路径、全部默认字段 | 实际量测完整输入、目录和详情，含危险/行动材料；超预算先修默认值/模板，不静默截断未结束事项 |

## 操作及持久接线

| 输入情境 | 预期结果 |
| --- | --- |
| create 同时建父关联/聚焦，父 ID 错误或任一额度不足 | 无 Goal/Link/Focus/身份计数的部分变更 |
| JSON 重复/未知键、错类型、非法 Unicode、batch 数组、尾文本 | 拒绝并有可纠正反馈；完整原始提交身份仍按现有协议记录 |
| update 缺字段与显式 null，或带状态不允许的字段 | 缺省保持，合法可选字段清空；非法整项拒绝 |
| 成功编辑/show/no-op 与拒绝 | 成功按既有服务规则轮转，拒绝不轮转；都不推进时间或确认警告、不返还预算 |
| 移动中的既有感知输入机会 | 允许目标操作，移动期限不变；没有输入机会时不凭目标工具唤醒角色 |
| 同一控制器先服务 A 再服务 B，双方都有 G1 | 只能访问绑定角色的集合；目标操作不通知对方或消耗通信额度 |
| 新 Context、handoff、use、其他角色操作、拒绝、关闭/终局及 S 重建 | 相关 interaction wrapper 重建不得丢目标集合/计数；他人材料不出现私有目标变化 |
| 成功目标编辑 E 已持久而 S 失败 | 冷开按原效果恰一次安装；不重问模型、不重新分配身份；摘要/Changed 与真实前后态一致 |

## 查询与冻结投影

以下都是待实现测试序列，A/B 表示目标 ID，不表示角色。

| 序列 | 预期结果 |
| --- | --- |
| show A → use/say/拒绝/真正 no-op | A 的冻结详情仍可见，并标明查询目标与操作序号 |
| show A → 改 Focus/任意 Goal/Link → 改回 | 详情标为过期；不因最终值相同而复活，delta 也提示失效 |
| show A → show B → edit B | B 过期，不退回 A |
| show A → show 不存在的 B | A 仍明确署名；B 拒绝另给短反馈，不伪称已查到 B |
| show A → 多次无变化操作使 show 退出回执窗口 | 仍从成功 Item 读取 A；呈现窗口不删除查询来源 |
| show A → E-only 中断 → 冷开 | 相同查询目标、快照和操作身份；不另调控制器 |
| 多次长编辑/查询/目标拒绝 | 完整输入只含一次默认目标区、一次有效详情及有界短回执；旧 RawInput/Effects 长正文不重复混入；非目标经历不受裁剪 |
| forget A 后重绘旧 Context 或 show A 时的前缀 | 从同一历史前缀选择目标、回执及查询；保留当时 A，不读今天图 |
| 放行世界进入新 Context | 目标集合保留；旧 show 不续传，新默认目录完整 |

## 证据层次

局部规则测试覆盖状态和图不变量；真实 E-only / S 冷开验证发布边界；冻结观察及 full/delta 检查呈现和隐私。模型能否正确区分误判与成果失效、是否合理切焦点，必须用用户故事中的实际调用观察，不能由这些规则测试代证。
