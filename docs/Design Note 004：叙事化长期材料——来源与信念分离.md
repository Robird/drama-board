# Design Note 004：叙事化长期材料——来源与信念分离

**状态：WP20 已采纳。日期：2026-08-17。**

## 问题

WP19 真场中，LLM 整体重写记忆后遗失了会面约定。最小修补原拟增加每轮不可变的 `Scene Briefing`，但这会把“角色收到过什么信息”和“角色目前相信什么”混为一谈：持续出现的系统陈述容易被模型当成不容怀疑的真相，压缩了误导、怀疑和重新解释的戏剧空间。

## 裁决：保存来源，不冻结信念

Player 增加 `ReferenceMaterial(Id, Source, Content)`。它表示角色可以反复查阅的叙事内材料，例如匿名信、案情笔记、战争公告抄本或过去会面后留下的备忘。

- `Source` 与 `Content` 每轮稳定渲染，解决原文被摘要丢失的问题。
- 稳定只意味着“材料仍这样写”，不意味着内容真实、仍然有效或角色必须相信。
- 角色对材料的信任、解释和反证仍写入可变 Memory。
- 材料属于 Player 私有输入，不进入世界 journal，也不绕过 Observation 获得新的世界知识。

渲染顺序为 `[可反复查阅的材料] → [内心状态] → [当前观察]`。材料先出现，角色较新的解释随后出现；system 同时明确“来源稳定不等于真实”。

## 与 WorldObject 的边界

第一版不要求每张纸条都成为世界对象。判断标准是载体变化是否具有游戏后果：

- 只需保证原文长期可查：使用 `ReferenceMaterial`。
- 需要被展示、转交、偷走、烧毁或遗失：提升为 `WorldObject`，由世界事件和 Observation 决定谁还能读取。

这种延迟物化是有意的原型边界，不建立通用 attribute/permission 系统。

## 非目标

- 不用材料替角色选择行动或维持计划。
- 不声称材料是真实世界事实。
- 不解决单块 Memory 整体重写造成的跨类别遗忘；该问题由 WP21 的分块 MemoryBank 处理。

## 验收

1. 完整替换 Memory 多轮后，材料来源与原文仍逐轮出现。
2. 可变 Memory 能同时表达与材料相反的判断。
3. 无材料的 Player 保持可用，不要求 Kernel、Host 或 Protocol 改动。
