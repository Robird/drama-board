# Documentation archive

This directory preserves evidence that is not a current implementation instruction. Start from [PROJECT-STATE](../../PROJECT-STATE.md) and [the documentation index](../README.md) for current work.

- [StateJournal-native experiments](statejournal-native.md) records retained conclusions and the fixed tag for the removed test-only probe.
- [Legacy work packages](legacy/legacy-work-packages.md) preserve early task sequencing and acceptance records.
- [Agent memory notebook](legacy/agent-memory-notebook.md) preserves the retired handoff snapshot.
- [Assistant infrastructure notes](legacy/assistant-infrastructure-notes.md) preserve an early assistant dialogue and its proposals.
- [Grid Spatial Framework](legacy/grid-spatial-framework.md) preserves the superseded Grid model.

The `legacy/` subtree is excluded from default local text search. Inspect its content with `rg --no-ignore -n "keyword" docs/archive/legacy`, or list it with `rg --files --no-ignore docs/archive/legacy`.

Historical documents retain their original claims and dates. They are evidence of a prior decision, not authority for a new task.
